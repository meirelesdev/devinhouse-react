# Devinhouse React

> Projeto React desenvolvido no modulo de frontend do bootcamp DevinHouse, com React Router, Formik, Styled Components e integracao com API via Axios.

## Stack

- React
- Styled Components
- Formik
- Axios

## Prerequisitos

- Node.js v14+

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/devinhouse-react.git
cd devinhouse-react

# Instale as dependencias
npm install

# Inicie a aplicacao
npm start
```
